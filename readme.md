# 🎯 Video Like Recommendation Engine

> Легковесное веб-приложение на Python для генерации персональных рекомендаций видео на основе истории лайков. Использует коллаборативную фильтрацию с приоритетом свежести и частоты взаимодействий.

## 📋 Описание
Система принимает имя пользователя и параметр `Nv` (количество последних лайков), анализирует поведение похожих пользователей, исключает уже просмотренный контент и формирует ранжированный список рекомендаций. Отчёт выводится в HTML с возможностью мгновенного скачивания в `CSV`.

## 🚀 Возможности
- ✅ Автоматическая генерация реалистичных тестовых данных через `Faker` (с проверкой существования файлов)
- ✅ Алгоритм рекомендаций на основе пересечения интересов (`user-based collaborative filtering`)
- ✅ Веб-интерфейс с выпадающим списком пользователей (Bootstrap 5)
- ✅ Встроенный экспорт результатов в CSV без дополнительных эндпоинтов (`data URI`)
- ✅ Обработка дат, дедупликация и защита от пустых выборок

## 🛠 Стек технологий
| Категория | Инструменты |
